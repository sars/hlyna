# Голос сайту

**Напрям:** «теплий майстер» + гончарська мова (`glossary.md`) + образність, навчена на Коцюбинському (`reference-kotsiubynsky.md`). Чотири варіанти на реальних текстах: `samples.md` (сторінка для порівняння: `voice_samples.html`). Остаточний варіант обирає власник.

## Порядок на кожній сторінці
1. **Перші 2–3 речення — прості й фактичні**, з цифрами і датою. Їх цитують пошуковики й ЛЛМ. Без образів.
2. **Далі — голос:** одне-два речення з образом (дотик, колір, звук, вогонь), одне гончарське слово з поясненням.
3. **Таблиці, списки, FAQ — знову просто.** Образність не заважає знайти ціну чи термін.

## Правила
- Пишемо як майстер, що говорить з гостем у майстерні: тепло, без пафосу, без канцеляриту.
- Конкретні речі замість загальних: «полива», «горн», «Ворскла», «3–8 тижнів», а не «унікальна якість».
- Ритм: довге речення-хвиля, потім коротке.
- Матеріал живий: глина «слухається», «тікає», «дзвенить після випалу».
- Не вигадуємо фактів заради краси. Образ — так, неправда — ні.
- Без емодзі, без «найкращий», «унікальний», «справжній шедевр».
- Українська мова, сучасний правопис; гуцульські й гончарські слова — з поясненням.

## Перевірка перед публікацією
- Чи зрозуміло з перших двох речень, що це за сторінка і скільки коштує?
- Чи є хоч один образ і хоч одне гончарське слово (на сторінках з текстом)?
- Чи немає вигаданих цифр, студій, відгуків?
