# Гончарська мова: словник для текстів сайту

Наша «особлива мова» — справжня лексика українських гончарів. Вживаємо ці слова природно і пояснюємо їх при першій появі на сторінці (коротко, в дужках або наступним реченням). Це робить тексти впізнаваними і водночас корисними для пошуку: люди шукають саме ці слова.

| Слово | Що означає | Як вживати |
|---|---|---|
| **полива** | Традиційна назва глазурі: скловидне покриття, яке після випалу робить виріб гладким і водонепроникним | «Тарілки під зеленою поливою»; «поливаний посуд» |
| **ангоб** | Рідка кольорова глина, якою покривають або розписують виріб | «Білий ангоб під прозорою поливою» |
| **мальовка** | Розпис ангобами, характерний для Опішні | «Опішнянська мальовка: квіти, птахи, хвилі» |
| **ріжок** | Інструмент для розпису тонкою цівкою ангобу (колись із ріжка тварини) | «Візерунок нанесли ріжком» |
| **ріжкування** | Розпис ріжком: лінії, крапки, хвилі | — |
| **фляндрівка** | Розпис, коли по свіжому ангобу ведуть пером чи шпилькою, і смуги розтікаються мармуровими розводами | «Чашки з фляндрівкою» |
| **гончарне коло (круг)** | Обертовий станок для формування посуду | «Витягнути миску на колі» |
| **центрування** | Перший крок на колі: глину вирівнюють точно по центру | Для текстів майстер-класів |
| **сирець** | Висушений, але ще не випалений виріб | «Поки виріб — сирець, його легко зламати» |
| **випал** | Обробка вогнем у печі; зазвичай перший (без поливи) і другий (з поливою) | «Після двох випалів чашку можна забрати» |
| **горн** | Гончарна піч | «З горна виходить дзвінкий черепок» |
| **черепок** | Випалена глиняна маса, «тіло» виробу | «Щільний черепок не вбирає воду» |
| **теракота** | Неполивна червона кераміка | «Теракотові горщики» |
| **майоліка** | Кераміка з непрозорою поливою і розписом | — |
| **кахля** | Керамічна плитка для печей; косівська кахля — окреме мистецтво | «Косівські кахлі» |
| **чорнодимлена кераміка** | Чорний посуд, який отримує колір від диму під час випалу (Гаварецька кераміка) | — |
| **лощіння** | Полірування сирого виробу каменем до блиску | — |
| **кракле** | Дрібна сітка тріщинок у поливі, задумана як декор | — |
| **глек, глечик** | Посудина для рідин з вузьким горлом | — |
| **макітра** | Широка глибока посудина, в якій розтирали мак | — |
| **горщик** | Посудина для варіння і зберігання | — |
| **миска, полумисок** | Глибока тарілка; полумисок — велика плоска страва для подачі | «Полумисок для подачі на стіл» |
| **куманець** | Обрядова посудина у формі кільця, з носиком | Для добірок і подарунків |

**Місця й річки** (конкретика замість загальних слів): Опішне на Ворсклі, Косів на Рибниці, Гаварецьке, Дибинці, Бубнівка, Васильків.
